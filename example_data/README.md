# Example data

This directory contains a small **Strike the gong** subset derived from
[AgiBot World Beta](https://huggingface.co/datasets/agibot-world/AgiBotWorld-Beta)
and converted to LeRobot v3.0 format. It is used by
[`configs/example_agibot_world_gong/`](../configs/example_agibot_world_gong/).
